# Heritage Themes for DrRacket

Colour themes drawn from the colour traditions of different cultures. 65 dark and light colour schemes in 32 families, for DrRacket; each family maps the named colours of one tradition to syntax roles.

This repository holds the Racket package that [Heritage Themes](https://github.com/heritage-themes/heritage-themes) generates for each release. Report problems and make changes there.

## Install

In DrRacket, choose **File | Install Package...**, enter `heritage-themes` and click **Install**. In a terminal:

```bash
raco pkg install heritage-themes
```

Restart DrRacket and choose a scheme under **Edit | Preferences | Colors | Color Schemes**; on macOS, **Preferences** is in the **DrRacket** menu. DrRacket lists the dark schemes and the light ones apart and keeps one of each: **Color Mode** chooses whether it follows the system's dark mode or always uses one of them.

Update with `raco pkg update heritage-themes` or in **File | Package Manager**, and restart DrRacket. Remove with `raco pkg remove heritage-themes`.

To install without the package catalog, download `heritage-themes-drracket-<version>.zip` from the [latest release](https://github.com/heritage-themes/heritage-themes/releases/latest) and install the file, naming the package:

```bash
raco pkg install --name heritage-themes heritage-themes-drracket-<version>.zip
```

## What is coloured

Each scheme colours the definitions and interactions windows: code, the background, line numbers, matching parentheses, the REPL's values, output and errors, error highlights, Check Syntax's identifiers, arrows and highlights, test coverage and the stepper's highlights. DrRacket draws its window, toolbar, menus, dialogs and the selection with the system's theme, and on Linux also the current line's number.

Racket's lexer gives names the text colour and the forms that it indents specially, such as `define`, `lambda` and `let`, the keyword colour. After **Check Syntax**, imported names take the colour of function calls, names bound in the program keep the text colour, and mutated variables are underlined.
